# boretube v2 — P1 plan (app core)

Spec: `docs/superpowers/specs/2026-10-28-boretube-v2-design.md`. P0 is done: the Dart ADB client works against the VU3, and absolute volume set is ignored by the TV while volume key events work.

Each task ends with `flutter analyze` clean and `flutter test` green, and gets its own commit.

1. **ADB identity + connection manager.** Generate an RSA-2048 key with pointycastle and keep it in flutter_secure_storage. `AdbSession` adds reconnect, keep-alive and auth-pending state (UI: "Look at the TV → Always allow").
2. **TV model + discovery.**
   - `Tv` (stable id, name, maker, model, ip, ports, lastSeen) and `TvStore` (multiple TVs, active id). Migrate the old `tv_config` prefs into it.
   - Discovery runs mDNS (`multicast_dns`: `_googlecast._tcp`, `_adb._tcp`, `_boretube._tcp`), SSDP DIAL M-SEARCH and a subnet sweep (8008+8009, 50 parallel, 600 ms, own /24 + gateway list) together, then merges and identifies via device-desc.xml.
   - Re-locate a moved TV by id.
3. **Capabilities.** Probe cast / dial / sonyRest / adb / agent, cached per TV with a timestamp.
4. **TvOps + profiles + journal.**
   - Typed ops (stopApp, setAppEnabled, stockYouTube, speechRollback, applyCleanup, launcherHealth, listApps, volumeStep, mute).
   - A never-touch guard and a verify read after every write.
   - JSON profiles in `assets/profiles/` (`sony-bravia-vu3`, `generic`).
   - A per-TV journal in prefs.
   - Health checks with check/fix pairs.
5. **Instant actions.** One `ActionsService` for Mute/Unmute, Stop app, Bore, Volume → N, Pause N min and Restore. It picks the best transport per capability: Sony REST, then ADB key events, then Cast.
6. **UI shell.**
   - Parent PIN lock; biometric is optional, via local_auth.
   - Top bar: TV switcher + status pill.
   - Onboarding: find → connect → ADB guide → PIN.
   - Tabs:
     - **Now:** now-on-TV, quick actions, classic lock card. This ports the existing lock and whitelist with no feature lost.
     - **Rules:** placeholder until P2, with an "Install TV Guard — coming in P2" note.
     - **TV:** Health, Apps (incl. the YouTube card), Activity journal, Settings.
7. **Android.**
   - Manifest: `CHANGE_WIFI_MULTICAST_STATE`, `ACCESS_WIFI_STATE`, `ACCESS_NETWORK_STATE`. Set minSdk.
   - Build a debug APK and smoke-test it on the phone.
